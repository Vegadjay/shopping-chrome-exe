# ReviewGuard

ReviewGuard is a React + TypeScript web app for the extension landing page.

## Development

Requirements:

- Node.js 18+
- npm

Run locally:

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
```

Preview production build:

```sh
npm run preview
```

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
